# Nicole Lillian Mark - Portfolio Website

A modern, responsive portfolio website built with Astro, showcasing data science expertise, academic work, and professional experience.

## 🚀 Features

- **Modern Design**: Clean, professional layout with dark mode support
- **Responsive**: Works perfectly on desktop, tablet, and mobile devices
- **Fast Performance**: Built with Astro for optimal loading speeds
- **SEO Optimized**: Proper meta tags and structured data
- **Blog System**: Markdown-powered blog with content collections
- **Portfolio Showcase**: Dedicated sections for projects and visualizations

## 📁 Site Structure

- **Homepage**: Professional introduction and overview
- **CV**: Complete curriculum vitae with education, experience, and skills
- **Academic Work**: Current research and academic projects
- **Publications**: Research papers and academic contributions
- **Portfolio**: Data visualization projects and applications
- **Blog**: Technical articles and insights
- **Media**: Speaking engagements and podcast appearances
- **Contact**: Professional contact information and form

## 🛠 Technology Stack

- **Framework**: [Astro](https://astro.build/) - Modern static site generator
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) - Utility-first CSS framework
- **Content**: Markdown with frontmatter for blog posts and content
- **Deployment**: GitHub Actions + GitHub Pages
- **Icons**: Emoji and Unicode symbols for visual elements

## 🚀 Development

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Local Development
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

### Deployment
This site automatically deploys to GitHub Pages via GitHub Actions when changes are pushed to the `main` branch.

## 📝 Content Management

### Adding Blog Posts
1. Create a new `.md` file in `src/content/blog/`
2. Add frontmatter with title, description, date, and tags
3. Write your content in Markdown
4. Commit and push - the site will automatically rebuild

### Updating CV
Edit `src/pages/cv.astro` to update professional information, experience, and skills.

### Adding Portfolio Projects
Update `src/pages/portfolio.astro` to showcase new projects and visualizations.
